# Retained study inputs

- `LfU_Schweinfurt_HQ100_HQextrem.gpkg`: Bavarian Environment Agency (LfU)
  flood-hazard extents HQ100 and HQextrem for the Main, Wern, and Marienbach
  (WWA Bad Kissingen), retrieved 30 September 2026. Source:
  https://www.lfu.bayern.de/wasser/hw_risikomanagement_umsetzung/hwgk_hwrk/
  Source data retain the LfU terms and attribution.
- `seattle_route_overlay_600dpi.png`: classified installed/generated route
  overlay retained from the Seattle comparison. Underlying installed data:
  City of Seattle / Seattle Public Utilities; generated routes and
  classification: Urban4. See the manuscript's Seattle data references.
- `heat_power_map_reference.pdf`: vector map geometry retained from the final
  heat-power figure. Base map: OpenStreetMap contributors (ODbL); generated
  networks and analysis: Urban4.

The source-code MIT licence does not replace the terms of these underlying
geospatial data sources.
