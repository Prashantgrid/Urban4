# Urban4 cases

- [Schweinfurt, Germany](schweinfurt.json): main Urban4 municipality-scale application, with supporting code and results in the repository.
- [Győr, Hungary — v0.2](gyor/README.md): synthetic four-network baseline with retained acceptance results and a [partner data request](gyor/partner_data_request.csv). The complete ZIP of native models, GIS layers, evidence snapshots and case generation scripts is **distributed separately** and is not yet hosted on GitHub.

The Győr files are provided for partner checks of local infrastructure extent, demands, installed assets and operating conditions. All stated solver checks are conditional on the assumed synthetic design.
